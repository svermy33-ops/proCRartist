# 일반 ZIP 백업 — M6 Architecture v3

이 파일들은 각각 독립적으로 열 수 있는 일반 .zip입니다. .zip.001 형식이나 바이너리 조각이 아닙니다. 기존 분할본 대신 이 폴더를 사용하세요.

## 복원

1. Part01.zip부터 마지막 Part ZIP까지 모두 다운로드합니다.
2. 모든 ZIP을 **동일한 대상 폴더**에 각각 압축 해제합니다. ZIP 이름별로 별도의 상위 폴더를 만드는 옵션은 끄세요.
3. 각 ZIP 안의 `BREAK_NORTH_M6_Architecture_v3` 폴더가 하나로 합쳐져야 합니다. 폴더 병합은 허용합니다. 같은 경로의 중복 파일은 없으므로 파일 덮어쓰기는 필요하지 않습니다.
4. 완성된 폴더의 README_KO.md에 따라 Unity에 적용합니다. 최신 artist handoff는 이 백업 폴더에 별도로 포함되어 있습니다.

각 ZIP은 정상적으로 열리지만, 전체 에셋을 사용하려면 모든 Part를 풀어야 합니다. ZIP들을 바이너리로 이어 붙이지 마세요. 이전 restore_windows.cmd / restore.py는 이 형식에 사용하지 않습니다.

전체 ZIP의 CRC 및 각 파일의 내용 해시를 검사하여 원본 ZIP 내부 파일과 누락·중복 없이 일치하는지 확인했습니다. 원본 ZIP 자체와 같은 바이트 파일을 복원하는 방식이 아니라, 내부 폴더와 파일을 동일하게 복원하는 방식입니다. GitHub 업로드는 아직 수행하지 않았습니다.
